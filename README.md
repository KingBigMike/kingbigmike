## 🔎 What I Do

**Offensive Security**
- Web application security testing with Burp Suite Pro, working through PortSwigger Web Security Academy labs
- Local lab practice against OWASP Juice Shop and DVWA
- Building toward bug bounty work on HackerOne and Bugcrowd

**Defensive Security & Detection Engineering**
- Deployed and tuned Wazuh SIEM, writing custom decoders and detection rules (`local_decoder.xml`, `local_rules.xml`) to catch attacks default rulesets miss
- Comfortable diagnosing log ingestion pipelines end-to-end — filebeat, `ossec.conf`, timestamp normalization, `wazuh-logtest`

**Malware Analysis & Incident Response**
- Static and dynamic analysis with PEStudio, x64dbg, ProcMon64, Regshot, and System Informer
- Full IR case study: investigated a real Rhadamanthys infostealer infection on my own machine — traced a malicious browser extension acting as a clipboard hijacker back to its infection vector, identified a pass-the-cookie account compromise, and rebuilt the entire timeline in an isolated VMware lab rather than just wiping and moving on

**Tooling & Scripting**
- Built a Flask-based C2 listener to understand attacker tradecraft from the inside
- Password recovery / forensics work with BTCRecover and John the Ripper
